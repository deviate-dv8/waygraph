Route folders = URLs

saucedemo-web/ is the namespace root for URL /. Child folders match Swag Labs paths.

Mapping

Swag Labs URLBlock folder
/saucedemo-web/
/inventory.htmlsaucedemo-web/inventory/
/inventory-item.htmlsaucedemo-web/inventory-item/
/cart.htmlsaucedemo-web/cart/
/checkout-step-one.htmlsaucedemo-web/checkout-step-one/
/checkout-step-two.htmlsaucedemo-web/checkout-step-two/

A folder gets NAV.md + nav Blocks if and only if that URL is a real page. Do not invent root/, landing/, or a parallel shell/nav/ tree.

Where each kind lives

  • Nav files at the route folder root.
  • Effect and Action files under that route's actions/.
  • Header links that navigate to a URL (cart, checkout) live on the destination route - e.g. nav-cart under cart/.
