waygraph auto on Sauce Demo

Prefer headed auto first - same menu rows as auto --cli (Add all / per-item Add / Open details / logout).

Commands

# In-repo (creds via --data)
cd examples/saucedemo
npm install
npm run auto              # headed panel - start here
npm run auto:cli          # terminal menu (same graph)
npm run prove:auto-cli    # scripted login -> add-all -> remove-all
npm run traverse          # graph crawl (Phase B-E); writes coverage.json
npm run traverse:parallel # --parallel 2 --session clone
npm run traverse:coverage # --min-edge-coverage 10% suite gate

# One-shot temp copy:
npx waygraph@latest try auto
npx waygraph@latest try auto:cli

Typical CLI path

  1. LoginPage - [1] submit-login
  2. LoggedIn - Add rows + Add all to cart
  3. After add-all - Remove rows + Remove all from cart
  4. q to quit

How the inventory menu appears

  1. Effects add-to-cart / remove-from-cart expose instanceOptions(page) - one labeled row per live button.
  2. Bulk Methods add-all-to-cart / remove-all-from-cart are one row each when matching buttons exist.
  3. nav-item-detail (MemNav) lists Open details per card.
  4. CLI and GUI share the same scanner - GUI adds hover rings + Hide/Show.
