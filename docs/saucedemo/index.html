Sauce Demo showcase

The in-package consumer that teaches waygraph conventions against live saucedemo.com - Nav, Effect, Action, route folders, and waygraph auto.

Source: examples/saucedemo · Pages folder: docs/saucedemo · npm waygraph@0.10.0+

What this showcase is for

  1. Convention, not a toy API sample. Folder layout and file suffixes match the consumer layout contract.
  2. TypeScript salt, real Blocks. Helpers force shape; the engine still runs plain Blocks - see Block kinds.
  3. Runnable proof. Prefer npm run auto:cli first (same menus as headed auto), then demos and Playwright.

Quick commands

cd examples/saucedemo
npm install && npx playwright install chromium
npm run auto:cli      # terminal menu - start here
npm run auto          # headed panel (same menus)
npm run demo          # headed stepper
npm test              # headless

# Or temp copy:
npx waygraph@latest try auto   # then npm run auto:cli in that folder
npx waygraph@latest try demo   # stepper + test
Block kinds Nav / Effect / Action - helpers are salt. Route layout saucedemo-web/ folders = Swag Labs URLs. waygraph auto Prefer auto:cli; same menus as headed panel. Source comments How each Block file documents its kind.
