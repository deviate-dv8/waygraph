Sauce Demo showcase

The in-package consumer that teaches waygraph conventions against live saucedemo.com - Nav, Effect, Action, route folders, waygraph auto, and demo narration (stubs / fixtures / captions / slides).

Source: examples/saucedemo · Pages folder: docs/saucedemo · npm waygraph@0.11.2

What this showcase is for

  1. Convention, not a toy API sample. Folder layout and file suffixes match the consumer layout contract.
  2. TypeScript salt, real Blocks. Helpers force shape; the engine still runs plain Blocks - see Block kinds.
  3. Demo narration coverage. All 0.11.0 narration features are shown in the checkout flow: stubBefore, stubAfter, flow fixtures, captions (label / detail / tag), and multi-step slides.
  4. Runnable proof. Prefer npm run auto (headed panel) first; use auto:cli for the same menus in the terminal.

Quick commands

cd examples/saucedemo
npm install && npx playwright install chromium
npm run auto          # headed panel - start here
npm run auto:cli      # terminal menu (same menus)
npm run traverse      # graph crawl + coverage.json (0.12.20+)
npm run demo          # headed stepper (narration, stubs, slides)
npm test              # headless

# Or temp copy:
npx waygraph@latest try auto
npx waygraph@latest try auto:cli
npx waygraph@latest try demo   # stepper + narration

Demo narration (0.11.0)

The checkout flow (src/flows/checkout.flow.ts) demonstrates every narration feature. Run npm run demo to see it live:

BlockFeatureWhat you see
submit-login stubBefore Rings on username / password / submit before the fill runs. Flow fixture overrides labels with AC copy + GATE tag.
add-to-cart stubAfter Cart badge ring after the click. Flow fixture adds detail and AC tag.
finish-order stubBefore + stubAfter + slides Ring on the Finish button before click (stubBefore); after resolve, 3 yap slides run in sequence - each pauses for Next slide; last slide resolves to stubAfter ring on the completion header.

Slides are separate from block lifecycle: they explain a long process step by step (slide 1 / 2 / 3), with Next between each. The block's pass/fail is not affected. Auto-advance checkbox in the panel skips manual Next. 

// finish-order.method.block.ts (abridged)
instruction: {
  stubBefore: { finish: { selector: "#finish", label: "Finish" } },
  stubAfter:  { thanks: { selector: ".complete-header", label: "Order confirmed" } },
  slides: [
    { caption: "Checkout is a short pipeline", detail: "Cart -> info -> overview -> done.", tag: "YAP" },
    { caption: "Finish submits the overview",   detail: "Only mutating step on this screen.", tag: "YAP", selector: "#finish" },
    { caption: "Completion banner is the proof",detail: "Thank-you header = durable signal.", tag: "YAP", selector: ".complete-header" },
  ],
}
// checkout.flow.ts - fixture overrides (unlimited demo purposes on .flow.ts)
withHighlightFixtures(flow, {
  "submit-login": {
    stubBefore: {
      username: { label: "Demo user",         detail: "standard_user from Mem.", tag: "AC" },
      password: { label: "Password",          detail: "Filled from Mem credentials." },
      submit:   { label: "Sign in",           tag: "GATE" },
    },
  },
  "add-to-cart": {
    stubAfter: { badge: { label: "Cart now has the item", detail: "Badge updates after add.", tag: "AC" } },
  },
  "finish-order": {
    stubAfter: { thanks: { label: "Order placed", detail: "Completion header is the proof.", tag: "GATE" } },
    // slides: [...] here would override the block's own 3-slide sequence
  },
});
