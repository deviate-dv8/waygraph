Waygraph

A typed graph of reusable Blocks for driving a browser through E2E flows (Playwright), instead of a flat pile of ad hoc helpers.

Package docs site · source deviate-dv8/waygraph · published URL after Pages is enabled: deviate-dv8.github.io/waygraph

Quick start Install, first Block + Flow, develop the package. Engine handout Core model, NavBlock, Traits, chainFlow, CLI, recommendations. Consumer layout Route folders = app URLs. No invented landing/root trees. Deploy / preview Local one-command preview and GitHub Pages workflow.

Install

npm install waygraph @playwright/test
npx create-waygraph my-project && cd my-project && npm install && npm test

Requires Node 22+. @playwright/test is a peer dependency (^1.40). Pin a published version for product work until you intentionally upgrade.

This site vs the package README

The package README remains the canonical API narrative in-repo. This Pages site packages the same material (plus consumer layout guidance) for browser reading and cross-mesh handoff.
