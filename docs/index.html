Waygraph

A typed graph of reusable Blocks for driving a browser through E2E flows (Playwright), instead of a flat pile of ad hoc helpers.

Getting started (pick one)

GoalCommand
Watch Sauce Demo in a browser (temp dir; Sign In + Shop + blocked Viewer) npx waygraph try demo
Interactive explore Sauce Demo (temp dir; CLI menu) npx waygraph try auto:cli
Interactive explore CLI (in-repo) cd examples/saucedemo && npm i && npm run auto:cli
Scaffold a new offline project (green npm test on a data: URL) npx create-waygraph my-app or npx waygraph init my-app
Add waygraph to an existing repo npm install waygraph @playwright/test

Scaffold lives in two places on purpose. create-waygraph is its own npm package (same offline template as waygraph init since 0.7.5) - scaffolding never pulls generator code into your app's runtime node_modules. waygraph init is the same shape when you already have the CLI installed. After either scaffold: cd my-app && npm install && npx playwright install chromium && npm test.

try demo copies the live Sauce Demo quickstart into an OS temp folder, runs step-through Sign In -> Shop & Checkout -> blocked Viewer login, then headless tests. Permanent tree: examples/saucedemo in this package. Offline empty scaffold: init / create-waygraph. Overlay details: Demo / run · Auto explore.

Requires Node 22+. @playwright/test is a peer dependency (^1.40). Pin a published waygraph version for product work until you intentionally upgrade.
