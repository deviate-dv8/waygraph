Scaffold structure

What npx waygraph init my-app and npx create-waygraph my-app copy (waygraph templates/scaffold/, 0.12+).

Source of truth in the package: templates/scaffold/STRUCTURE.md. Offline hello uses a data: URL so npm test needs no network.

After init

cd my-app
npm install
npx playwright install chromium
npm test
npm run demo              # headed step
npm run demo:auto-next    # auto-next + YAP slide
npm run list && npm run check

Growing past hello

  1. Point package.json waygraph.baseUrl at your app.
  2. Rename demo-web/ to your origin namespace (pia-web/, zsign-web/, …).
  3. Add one folder per real page.tsx URL; grouping dirs without a page get no NAV.md.
  4. Keep ticket copy on .flow.ts fixtures; blocks stay neutral stubs.
