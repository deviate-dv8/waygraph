Scaffold structure

What npx waygraph init my-app copies (waygraph templates/scaffold/, 0.12.7+). Includes auto (Effect instanceOptions), Page hub, narration, and mem - not a bare hello.

Source: templates/scaffold/STRUCTURE.md. Offline home.html via local fixture server :4177 (not file://) - no external network for npm test / auto.

Auto

cd my-app
npm install && npx playwright install chromium
npm run auto        # headed - after home, pick Add Alpha / Add Beta / …
npm run auto:cli    # terminal menus
npm run demo:shop   # scripted Effect path with --data selectedItem

Auto fills SelectedItem when you pick an Effect menu row. Hand-written flows pass --data '{"demo.selectedItem":{…}}'. More: Auto explore.

Coding agents

Mirror of Playwright init-agents: 

npx waygraph agent-dive --loop claude
npx waygraph agent-dive --loop opencode
npx waygraph agent-dive --loop cursor
npx waygraph agent-dive --loop vscode --prompts

Writes planner / author / healer agent files into the project so an agent can dive an existing app into Nav/Page/Method/Effect coverage.

Growing past the fixture

  1. Point waygraph.baseUrl at your app; replace home.html nav with real routes.
  2. Rename demo-web/ to your origin namespace.
  3. One folder per page.tsx; keep Effects for DOM-instance menus.
