Demo narration: stubs + flow fixtures

Catch-all highlight lifecycle on every block; unlimited demo purposes on the issue .flow.ts. Proposal for waygraph (not shipped in 0.10.9).

RFC: docs/proposals/mod-highlights-rfc.md · mesh handout: .sm/seats/_shared/WAYGRAPH-HANDOUT.md §4.6b

Mental model

Every block     → stubBefore + stubAfter   (selectors + neutral labels; {} ok)
Issue .flow.ts  → highlightFixtures        (unlimited demo purposes per phase/slot)

Same pattern as Mem: the block declares slots; the flow owns the story. Shared blocks stay library-neutral. Ticket AC copy, BUG/GATE tags, detail lines, and any other demo purpose live on the flow.

HalfWhereRole
Stubs Every block instruction stubBefore + stubAfter — named slots (selector + neutral label). Catch-all lifecycle shape on every block ({} ok).
Fixtures Issue .flow.ts Unlimited demo purposes — AC copy, BUG/GATE tags, detail, ticket sentences. Override per block / phase / slot.

Not modHighlight() and not a modBlock* highlight decorator. (modBlockVerify is verify-only and unrelated.) The RFC filename mod-highlights is legacy naming only.

Phases

PhaseWhen demo runs itBlock (library)Flow fixture
stubBefore Before / during act Inputs / buttons the block touches Unlimited purposes before/during interaction
stubAfter After resolve + verify Post-step proof points Unlimited purposes after the step (AC / GATE / …)

Block (neutral)

instruction: {
  async act(page, _input, mem) { /* … */ },
  resolve: () => checkpoint("PiaLoginLinkSent"),
  verify: [Trait.visible("text=Check your inbox")],

  stubBefore: {
    email: { selector: "#email", label: "Email address" },
    submit: { selector: 'button[type="submit"]', label: "Send sign-in link" },
  },
  stubAfter: {
    sent: { selector: "text=Check your inbox", label: "Magic link sent" },
  },
}

Flow .flow.ts (unlimited purposes)

const highlightFixtures = {
  "method-pia-select-recommended-alternative": {
    stubBefore: {
      select: {
        label: "pia-pm#276 AC-3",
        detail: "Must not badge Active Plan yet.",
        tag: "BUG",
      },
    },
    stubAfter: {
      dialog: { label: "Dialog open", detail: "Card unchanged.", tag: "GATE" },
    },
  },
};

export const issue276Flow = withHighlightFixtures(
  withTitle(withSessionReset(engine.defineFlow([start, …chain, end])), "pia-pm#276 …"),
  highlightFixtures,
);

Fixtures merge onto stub slots (label / detail / tag; selector optional — inherit from the block). Do not invent selectors the block never declared.
