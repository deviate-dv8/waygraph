Deploy / preview

One local preview path; GitHub Actions deploys docs/ to Pages.

Local preview (one command)

From the package root:

npm run docs:preview

Serves docs/ on http://127.0.0.1:4173/ (static files only; no build step).

Equivalent without npm:

python3 -m http.server 4173 --directory docs

GitHub Pages (Actions)

  1. Workflow: .github/workflows/pages.yml uploads docs/ on push to main (and workflow_dispatch).
  2. Repo Settings → Pages → Build and deployment → Source: GitHub Actions (one-time).
  3. Published URL: https://deviate-dv8.github.io/waygraph/

Paths in the site are relative (./css/…, ./handout.html) so project Pages under /waygraph/ resolve correctly.

What is not on Pages

OpenSpec change folders, Playwright fixtures, and dist/ stay in the git repo only. Consumer proof apps live in sibling projects_waygraph/.
