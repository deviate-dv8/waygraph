Demo / step / autoplay

How to watch a flow in the browser. Agents confuse demo, --step, and --autoplay constantly - this page is the contract.

Pick the command

WantCommand
Watch a named flow (manual Next) npx waygraph demo shopFlow .
Same, but auto-advance on a timer npx waygraph demo shopFlow . --autoplay
Watch an ad-hoc Block chain npx waygraph chain "login then nav-cart" . --step
One-shot Sauce Demo onboarding (temp dir) npx waygraph try demo
Interactive explore (in-repo) cd examples/saucedemo && npm run auto
Run with no overlay npx waygraph demo shopFlow . --no-step

demo is the friendly wrapper: it turns step ON and autoplay OFF unless you pass flags. chain --step is the same overlay on an ad-hoc spec. try demo copies Sauce Demo into a temp folder, runs Sign In + Shop + blocked Viewer, then npm test. Permanent example: examples/saucedemo. Interactive picker: Auto explore.

Step vs autoplay (two different knobs)

FlagWhat it does
--step Headed overlay: show MemKeys, gate the Block, highlight verify Traits, then Next. Implies headed. Default for demo and try demo.
--no-step No overlay. Runs straight through (headless unless you also set headed).
--autoplay Only meaningful with step. Starts the panel with Auto-advance checked - timer moves to the next gate (default ~1800ms; WAYGRAPH_AUTOPLAY_MS).
--no-autoplay Starts with Auto-advance unchecked. You click Run this step / Next. Default for demo. 
# Manual watch (default)
npx waygraph demo shopFlow .

# Auto-advance watch
npx waygraph demo shopFlow . --autoplay --title "Shop demo"

# Force manual after a previous autoplay session
npx waygraph demo shopFlow . --no-autoplay

# Overlay on a chain (step is NOT default on chain - pass it)
npx waygraph chain "login then nav-cart" . --step --no-autoplay

What you see in the browser

  1. Purple overlay panel: Block name, MemKeys (editable), episode breadcrumb.
  2. Run this step (manual) or Auto-advancing... (autoplay) - then Playwright runs that Block.
  3. Highlight ring over verify Traits; click Next (or wait if autoplay).
  4. Mid-run: flip the Auto-advance checkbox anytime. A manual click always wins over an in-flight autoplay wait.
  5. Hide / Show in the panel chrome (persisted). On phones the panel is a bottom sheet so the page stays usable.

NavBlock click shows cursor travel + pulse before the real click. NavBlock url still uses page.goto.

Headed vs headless

ModeCommand
Headed stepper waygraph demo shopFlow . (default --step)
Headed + Auto-advance waygraph demo shopFlow . --autoplay
Headless (no overlay) waygraph demo shopFlow . --no-step or npm test
Record video headless npx waygraph try demo --video ./out --no-step

CLI command order (agents)

Prefer this order when reading waygraph --help:

  1. demo / try - watch
  2. chain / run - execute
  3. list / nav / validate - inspect flows
  4. check / auto / graph - hygiene + graph
  5. init - scaffold

Common mistakes

  • Expecting chain to open the overlay without --step - only demo / try demo default step ON.
  • Thinking --autoplay alone is enough - without step there is no panel. Use demo … --autoplay or chain … --step --autoplay.
  • Using WAYGRAPH_STEP=1 soup instead of flags - flags beat env; prefer --step / --autoplay.
