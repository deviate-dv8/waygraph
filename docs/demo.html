Demo / run (less is more)

Three primary verbs: auto, demo, run. Flags compose. Prefer --blocks + --data over a flag forest.

Pick the command

WantCommand
Watch a flow (manual Next) npx waygraph demo --blocks shopFlow
Auto-advance steps npx waygraph demo --blocks shopFlow --auto-next
QA: watch + record npx waygraph demo --blocks shopFlow --auto-play-video
Ad-hoc Blocks + mem seed npx waygraph run --blocks "loginFlow then add-all-to-cart" --data '{…}'
Headed execute + video npx waygraph run --blocks shopFlow --non-headless --video
Explore (CLI first) npx waygraph auto --cli --data '{…}'
Onboarding (temp dir) npx waygraph try demo / try auto

Positional flow/spec still works (demo shopFlow) - prefer --blocks for clarity. Compat: chain -> run --blocks; --autoplay -> --auto-next.

Flags

FlagWhereWhat it does
--blocks demo / run / auto Flow or "a then b" spec. On auto only: --blocks From To = graph path-find between Checkpoints.
--data '{…}' demo / run / auto Mem seed JSON (keyed by MemKey name, e.g. saucedemo.credentials).
--auto-next demo Step overlay Auto-advance starts ON (alias --autoplay).
--auto-play-video demo only QA combo: --auto-next + --video (+ step).
--non-headless run Show the browser.
--video [dir] run / demo Playwright recordVideo (.webm).
--step / --no-step demo / run Overlay on/off. demo defaults step ON. 
# Manual watch (default)
npx waygraph demo --blocks shopFlow

# QA record
npx waygraph demo --blocks cartBulkFlow --data '{"saucedemo.credentials":{…}}' --auto-play-video

# Ad-hoc execute
npx waygraph run --blocks "loginFlow then add-all-to-cart then remove-all-from-cart" --data '{…}'
